# Agile Board Lab - 
## Team Roles
* **Coordinator:** Maryam - Maintains priorities, owners, and board status.
* **Developer:** Tooba - Implements the assigned technical task.
* **Reviewer:** Unzila - Checks clarity, design, and code changes.
* **Tester:** Malaika - Verifies acceptance criteria and records evidence.
## Workflow
We use a 5-column GitHub Project Board: **Backlog -> Ready -> In Progress -> Review -> Done**. 
A task only moves to 'Done' when all acceptance criteria are met and the tester has recorded evidence.
## Definition of Done
- [ ] The story satisfies every acceptance criterion.
- [ ] The assigned tester has verified the feature.
- [ ] Another team member has reviewed the work.
- [ ] The team has recorded evidence of the test result.
